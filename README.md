SkyCart - E-Commerce Web Application

SkyCart is a responsive, single-page e-commerce web application inspired by Amazon. Built using standard **HTML5**, **CSS3**, and **Vanilla JavaScript**, it provides an interactive shopping experience featuring dynamic product rendering, real-time search, category modals, and cart counter tracking.

Features

- **Dynamic Product Catalog:** Renders 36+ products across categories including Electronics, Appliances, Fashion, and Jewellery with formatted prices in INR (`₹`).
- **Real-Time Product Search:** Filters items instantly as you type into the search bar.
- **Interactive Shopping Cart Counter:** Live updates to the cart counter badge in the navigation bar upon adding items.
- **Single-Page Navigation:** Seamless toggle between the **Storefront** and the **About Us** page without reloading.
- **Sub-Navigation Modals:** Functional modal popups for header links (*Today's Deals*, *Customer Service*, *Registry*, *Gift Cards*, *Sell*).
- **Responsive Layout:** Adaptive grid design that scales across desktop, tablet, and mobile screens.

Tech Stack

- **HTML5:** Semantic markup and document layout.
- **CSS3:** Custom styling using Flexbox, CSS Grid, and media queries.
- **JavaScript (ES6+):** DOM manipulation, client-side filtering, and application state.
- **Font Awesome 6.7.2:** Icon assets via CDN.
